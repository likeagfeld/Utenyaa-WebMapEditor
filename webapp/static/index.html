Sprite design guide

Layout. Each character has 5 frames; the engine picks one based on facing angle:

  • frame 0 — south: facing the camera (default)
  • frame 1 — diagonal: SW / SE
  • frame 2 — north: facing away
  • frame 3 — side: W / E (mirror-flipped per side)
  • frame 4 — dead: charred / explosion KO sprite

Template. 80×80 RGBA PNG. 5 columns × 5 rows of 16×16 cells. Row = character index, column = frame index. Magenta pixels in the download template are placeholder transparency markers — replace with real colors or leave alpha = 0 on import.

Saturn quantization. The VDP1 only knows ARGB-1555 (5 bits R, G, B; 1 bit alpha). Your 8-bit-per-channel pixels get quantized on import (top 5 bits kept). Alpha < 128 → fully transparent; alpha ≥ 128 → fully opaque. There's no alpha blending — partial transparency is not representable on hardware.

Editor recommendations. Aseprite, GIMP, Photoshop, or Paint.NET all work. Set canvas to 80×80, disable smoothing/anti-aliasing, and export as PNG (8-bit RGBA). The template's 16×16 cells give you exactly enough room — don't draw across cell borders since each cell becomes one sprite frame.

In-game delivery. Phase 2 saves edits to the editor server only. Phase 3 (next iteration) will stream custom sprites to the Saturn during a match so other players see your character.
